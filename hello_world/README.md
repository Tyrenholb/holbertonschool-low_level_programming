# Hello, World and the C Compilation Pipeline

Four shell scripts explore preprocessing, compilation, assembly output, and
linking. Three standalone C programs introduce `puts`, `printf`, and `sizeof`.

## Requirements

- Compilation target: Ubuntu 20.04 LTS using GCC.
- Required options: `-Wall -Werror -Wextra -pedantic -std=gnu89`.
- Code must follow Betty style and pass
  [`betty-style.pl`](https://github.com/hs-hq/Betty/blob/master/betty-style.pl)
  and [`betty-doc.pl`](https://github.com/hs-hq/Betty/blob/master/betty-doc.pl).

## Files

| File | Behavior |
| --- | --- |
| [`0-preprocessor`](0-preprocessor) | Runs `gcc -E` on `$CFILE` and writes preprocessed output to `c` |
| [`1-compiler`](1-compiler) | Runs `gcc -c` and writes an object beside the source using its basename |
| [`2-assembler`](2-assembler) | Runs `gcc -S` and writes assembly beside the source using its basename |
| [`3-name`](3-name) | Compiles and links `$CFILE` into an executable named `cisfun` |
| [`4-puts.c`](4-puts.c) | Prints a quotation with `puts` |
| [`5-printf.c`](5-printf.c) | Prints a sentence with `printf` |
| [`6-size.c`](6-size.c) | Prints the sizes of `char`, `int`, `long int`, `long long int`, and `float` |

## Build

Bash is required for the scripts. Each C file has its own `main`; build them
separately. From the repository root:

```bash
cd hello_world
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 4-puts.c -o puts_example
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 5-printf.c -o printf_example
```

### Size-program compatibility

`6-size.c` uses `%zu` and `long long`, which trigger C90 compatibility
diagnostics with the required flags in local checks. The current source does
not pass the strict compilation command. To explore it while retaining those
warnings, use this explicit exception:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 -Wno-error=format -Wno-error=long-long 6-size.c -o size_example
```

This command is a local demonstration workaround, not the submission standard.
Reported sizes depend on the platform and compiler target.

## Betty checks

With Betty installed, run from this directory:

```bash
betty-style *.c
betty-doc *.c
```

The three C sources pass the installed Betty checkers locally. The stage
scripts are Bash files and are not inputs to the Betty C checkers.

## Usage

```console
$ ./puts_example
"Programming is like building a multilingual puzzle
$ ./printf_example
with proper grammar, but the outcome is a piece of art,
```

After building with the size-program workaround:

```bash
./size_example
```

To explore the compilation stages using the same source:

```bash
CFILE=4-puts.c bash 0-preprocessor
CFILE=4-puts.c bash 1-compiler
CFILE=4-puts.c bash 2-assembler
CFILE=4-puts.c bash 3-name
./cisfun
```

These scripts read the source filename from `CFILE`, not a positional argument.
They use their own minimal GCC commands and do not add the school warning
flags. Their output names are fixed or derived from `CFILE`; subsequent runs
can overwrite those outputs.

## Clean up

Remove the outputs generated by the examples above:

```bash
rm -f puts_example printf_example size_example c 4-puts.o 4-puts.s cisfun
```
